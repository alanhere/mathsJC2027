# HOW TO ADD A LESSON
# Copy a whole lesson from below, paste it anywhere in this file, then change the words.
# Lines that start with # are notes. The website ignores them.
# Every lesson starts with a date line. Write dates as year-month-day, like 2026-10-08.
# The order of lessons in this file does not matter. The website sorts them by date.
#
# date: 2026-10-08
# title: Name of the lesson
# topic: Algebra                (optional, shows a small tag under the lesson title)
# summary: A sentence or two on what we did in class.
# homework: Exercise 7C, questions 1 to 10 | https://drive.google.com/file/d/XXXX/view?usp=sharing
# board: 2026-10-08.pdf
# photos: 2026-10-08-1.jpg, 2026-10-08-2.jpg
#
# summary can be repeated for a second paragraph. It is optional.
# board is your whiteboard PDF, saved in the board folder. photos is optional and is for individual photos.
# solutions: https://drive.google.com/file/d/XXXX/view?usp=sharing
# video: A second video, optional | https://www.youtube.com/watch?v=YYYYYYYYYYY
# exitquiz: Exit quiz, refraction | https://isaacscience.org/questions/XXXX
# video: Worked answers to questions 4 to 10 | https://www.youtube.com/watch?v=XXXXXXXXXXX
# notes: Guided notes, chapter 7 | chapter-7.pdf
#
# You can have up to 3 video lines in a lesson. Each one goes on its own line. Extra ones after three are ignored.
# exitquiz is optional. Paste an isaacscience.org link. Leave the line out and no exit quiz shows.
# Homework and solutions are Google Drive share links. Paste the whole link.
# photos can be file names from the photos folder, like 2026-10-08-1.jpg, or Drive links.
# You can also give a photo a caption: 2026-10-08-1.jpg | Left board: worked examples
# (keep each photo entry on one line, and avoid commas in captions)
# notes can be a PDF file name from the notes folder, like chapter-7.pdf, or a Drive link.
#
# Everything after the first colon is the content. Keep each line on one line.
# Delete the sample lessons below once you have added your own.
# ---------------------------------------------------------------
